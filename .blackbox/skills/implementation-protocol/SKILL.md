# Implementation Protocol

Every implementation must follow this workflow.

Diagnosis

↓

Architecture Audit

↓

Gap Analysis

↓

Alternative Solutions

↓

Recommendation

↓

Implementation Plan

↓

User Approval

↓

Implementation

↓

Validation

↓

Documentation

↓

Final Certification

Never skip any phase.

Never implement code without understanding the current architecture.

Always minimize changes.

Always maximize reuse.

Always preserve compatibility.
