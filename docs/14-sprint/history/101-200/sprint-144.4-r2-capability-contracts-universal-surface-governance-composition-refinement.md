## ADJUSTMENT N°1 — UNIVERSAL CAPABILITY SURFACE PRINCIPLE

Se certifica oficialmente:

```
Universal Capability Surface Principle
```

Capability Contracts constituye la **única superficie pública oficial** del Capability.

Todo consumidor deberá acceder exclusivamente mediante:

```
Capability Contracts
```

Queda prohibido consumir directamente:

```diff
- ❌ Alert Evaluation
- ❌ Alert Status
- ❌ Capability Events
- ❌ Internal Contracts
- ❌ Runtime Objects
- ❌ Internal Domain Models
```
