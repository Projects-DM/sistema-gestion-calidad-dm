## ADJUSTMENT N°1 — ARCHITECTURAL ADMISSION PRINCIPLE

Toda extensión certificada deberá completar el siguiente ciclo:

```
Proposal

↓

Architecture Validation

↓

Governance Validation

↓

Certification

↓

Architectural Admission
```

Nunca mediante:

```diff
- ❌ Direct Registration
- ❌ Manual Core Integration
- ❌ Runtime Admission
- ❌ Infrastructure Admission
```
