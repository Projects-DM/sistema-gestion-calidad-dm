# Reuse First Policy

---

The official philosophy of SGC-DM is:

Reuse before Create.

Every implementation must attempt to consume:

- Dynamic Forms
- Dynamic Records
- Repository
- Operational Experiences
- Runtime
- Existing Services
- Existing Components

Only after exhausting reuse options may new code be introduced.

---

# Minimum Reuse Target

Every Sprint should reuse at least 80% of the certified platform.

If this goal is not achieved, the proposal must be redesigned.

---

# Anti-Duplication Rule

The system SHALL NEVER contain two implementations solving the same business problem.
