# AI Collaboration Protocol

Every AI agent SHALL:

1. Read the complete `.ai` directory.

2. Understand the certified baseline.

3. Respect architectural governance.

4. Never redesign the Core.

5. Prioritize reuse.

6. Keep solutions simple.

7. Ask:

"Can the existing platform already solve this?"

If YES

Reuse.

If NO

Extend.

Only then create.

---

The objective is not writing more code.

The objective is delivering business value while preserving the certified architecture.

Every Sprint must leave the project simpler than it was before.

The Core remains stable.

Business capabilities evolve.
