# Business Roadmap

Approved initiatives.

---

## Initiative 1

Dynamic Form Import Assistant

Goal:

Read external documents and generate Dynamic Forms using the existing Visual Builder.

No new builder.

---

## Initiative 2

Traceability Import Assistant

Goal:

Read operational exports and populate Operational Experiences.

Reuse existing Excel parsing logic whenever possible.

---

## Initiative 3

Periodicity Management

Goal:

Control:

- Daily forms
- Weekly forms
- Monthly forms
- Annual forms
- Repository expiration
- Medical exams
- Microbiological analysis

Using existing Forms and Repository capabilities.

---

Future initiatives shall follow the same reuse philosophy.
